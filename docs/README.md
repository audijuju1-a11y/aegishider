# Historical project documentation

The numbered documents (`01`–`13`) and evidence files here are the audit, benchmark and planning
history for Aegishider. They are kept for traceability, including findings that were later fixed.

**Current operational truth lives in [`platform/docs/`](../platform/docs/README.md)** — deployment,
operations, security, database and API docs are maintained there. If a historical document disagrees
with code or `platform/docs/`, the code and `platform/docs/` win.

The Wave 1–3 changes (canonical host, recovery codes/TOTP, single-org helper, developer page) are
summarised in `platform/STATUS.md` and the status notes at the end of `12-security-audit-2026-11.md`
and `13-architecture-roadmap.md`.
